Approved active IT discovery

A persistent queue and separate worker enforce per-target permission and bounded probing.

100%
Open SVGDownload SVGDOT source

Zoom for detail. Scroll or use arrow keys inside the diagram to explore. Dashed arrows show feedback or external human steps.

Decision boundaries

  • At most one active run per database; 30-second scan timeout, 180-second execution bound, and constrained pacing. No CIDR expansion, scripts, UDP or OS fingerprinting.
  • Identification is limited to SSH 22, HTTP 80/8080 and HTTPS 443/8443. Redirects/authentication are disabled; TLS failures remain explicit.
  • No response is not proof a device is offline. Results never auto-expand permissions or scan OT endpoints.

  6. Deduplicated persistent queued run bound to permission revision
  7. Separate worker claims database-wide lease
  8. Another valid lease active?
  9. Busy; do not overlap workers
  10. Expired running work becomes Interrupted; no automatic replay
  11. Revalidate permission, eligibility, revision and cancellation
  12. Cancelled: operator request or changed / revoked target
